# Portofolio — Mirwakhatul Jannah

Website statis (HTML + CSS murni, tanpa build tool) siap di-hosting gratis lewat GitHub Pages.

## Cara hosting di GitHub Pages

1. Buat repository baru di GitHub, misalnya `portofolio-mirwakhatul`.
2. Upload seluruh isi folder ini (`index.html` dan folder `assets/`) ke root repository tersebut.
   - Lewat web: klik **Add file → Upload files**, seret semua file & folder, lalu commit.
   - Lewat git: `git add . && git commit -m "portofolio" && git push`.
3. Buka **Settings → Pages** di repo tersebut.
4. Pada **Branch**, pilih `main` dan folder `/ (root)`, lalu **Save**.
5. Tunggu 1–2 menit, situs akan aktif di:
   `https://<username-github-kamu>.github.io/portofolio-mirwakhatul/`

## Mengubah isi

Semua teks ada langsung di `index.html` (cari bagian yang ingin diubah, teksnya polos tanpa kode rumit). Foto ada di folder `assets/` — ganti file dengan nama yang sama untuk memperbarui foto.
